# Mini Katalog Uygulaması

## Kısa Açıklama
Bu proje, Flutter kullanılarak geliştirilmiş temel bir mobil katalog uygulamasıdır. İçerisinde ana sayfa, ürün listesi ve ürün detay ekranları barındırmakta olup, sayfalar arası veri taşıma ve liste elemanlarının dinamik olarak oluşturulması (JSON simülasyonu) gibi temel Flutter konseptlerini içermektedir.

## Kullanılan Flutter Sürümü
* Flutter Sürümü: [3.47.7]
* Dart Sürümü: [3.13.5]

## Çalıştırma Adımları
Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:

1. Repoyu bilgisayarınıza klonlayın:
   `git clone https://github.com/merveAydinDev/mini_catalog_app`
2. Proje dizinine gidin:
   `cd mini_catalog_app`
3. Gerekli Flutter paketlerini indirin:
   `flutter pub get`
4. Uygulamayı bir emülatörde veya fiziksel cihazda başlatın:
   `flutter run`
